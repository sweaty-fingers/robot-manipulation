# EXP-0001. 손가락 접촉 시점이 어긋나면 물체가 밀리는가

!!! tip "다시 돌리기"
    ```bash
    PYTHONPATH=. .venv/bin/python scripts/reproduce_async_push.py
    ```
    시드 0 고정. 같은 커밋이면 같은 수치가 나옵니다(2026-11-20 재실행에서 2026-11-14 결과와 같음).

## 1. 질문과 가설

**질문**: 연구 목표인 무교란 파지([배경 03](../background/03_touchless_grasping.md))의 출발점으로, 손가락이 서로 다른 시각에 물체에 닿으면 먼저 닿은 손가락이 물체를 밀어내는지 시뮬레이션에서 재현합니다.

**가설 H1**: 손가락 출발 시각의 어긋남(spread)이 클수록 세 손가락이 모두 닿았을 때의 물체 중심 변위가 커진다. 동시에 닫으면(spread 0) 변위는 거의 0이다.

## 2. 설정

| 항목 | 값 |
| --- | --- |
| 환경 | `ThreeFingerGraspEnv`(Phase B): 120° 간격 반지름 방향 슬라이더 손가락 3개, 테이블 위 원기둥(반지름 30 mm, 높이 60 mm, 0.1 kg), Drake point contact, 제어 주기 0.02 s, PD(kp 300, kd 15) |
| 비교 조건 | 손가락 출발 지연 = `[0, 0.5, 1.0] × spread`, spread ∈ {0, 0.1, 0.2, 0.4, 0.6, 1.0} s. 모든 손가락은 같은 속도(0.08 m/s)로 시작 반경 0.10 m에서 닫힘 |
| 측정 | 에피소드 끝(150 스텝)의 물체 중심 변위(mm), 세 손가락 모두 접촉 여부 |
| 실행 환경 | 시뮬레이션, 이 저장소의 `.venv`(Drake), 시드 0 |

## 4. 결과

`scripts/reproduce_async_push.py` 출력(2026-11-20 재실행):

| spread (s) | 물체 변위 (mm) | 세 손가락 모두 접촉 |
| --- | --- | --- |
| 0.00 | 0.01 | 예 |
| 0.10 | 1.94 | 예 |
| 0.20 | 4.67 | 예 |
| 0.40 | 12.58 | 예 |
| 0.60 | 15.46 | 예 |
| 1.00 | 16.36 | 예 |

- H1을 지지합니다. 동시에 닫으면 0.01 mm, 어긋남이 커질수록 변위가 커져 spread 1.0 s에서 16.36 mm입니다.
- 모든 조건에서 결국 세 손가락이 다 닿으므로, "쥐었다"는 판정만으로는 물체가 얼마나 밀렸는지 알 수 없습니다.

## 5. 실패와 해석

- spread 0.6 s 이상에서 변위가 16 mm 근처에 머무는 이유는 확인하지 않았습니다(추정: 늦은 손가락이 닿기 전에 먼저 닿은 손가락들이 목표 위치에 도달해 미는 거리가 제한됨).
- 한계: 시드 1개, 손가락당 1자유도, 원기둥 하나, point contact만(hydroelastic 속성 없음, [R5](../reference/r5_simulation_tools.md)). 실제 손의 컴플라이언스와 마찰 차이는 반영하지 않았습니다.

## 6. 결론과 다음 단계

- 이 환경이 "비동기 접촉 → 물체 밀림"을 재현하므로, 무교란 파지 방법을 비교하는 기준선으로 씁니다.
- 다음: 접촉 전에 도착 시점을 맞추는 방법이 밀림을 줄이는지 확인([EXP-0002](0002-arrival-sync.md)). 여러 시드와 hydroelastic 접촉으로 반복.
