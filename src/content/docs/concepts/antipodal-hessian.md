## 한눈에 보기

1. **Hessian은 "접점 두 개를 표면 위에서 살짝 움직였을 때, 둘 사이 거리 에너지 `E`가 어떻게 변하는가"를 알려주는 2차 정보**입니다.
2. 고유값 **부호**가 그 접점 쌍이 거리의 **극소 / 극대 / 안장** 중 무엇인지 결정합니다. (고유값 **크기**는 매개변수 `t`를 어떻게 잡았느냐에 따라 달라지므로 의미가 약하고, 부호를 보면 됩니다.)
3. 직관: 두 접점을 서로 끌어당기는 스프링을 상상하면, **극소 = 흔들어도 제자리로 돌아옴(안정)**, **극대 = 조금만 벗어나도 계속 벗어남(불안정)**, **안장 = 방향에 따라 다름**.
4. 주의: 이것은 "접점이 표면을 따라 **미끄러질 때의 기하학적 안정성**"이지, 마찰원뿔·힘 균형까지 포함한 **파지 성공 여부(force closure)** 를 직접 판정하는 값은 아닙니다. 둘의 관계는 [6절](#6-미끄러짐-안정성과의-관계)에서 정리합니다.

## 1. 복습: 에너지 함수와 임계점

도형 경계를 `p(t)`로 매개변수화하고, 접점 두 개를 `p(t₁)`, `p(t₂)`라 하면 에너지는 두 접점 거리의 제곱에 비례합니다.

```
E(t₁, t₂) = ½ κ ‖p(t₁) − p(t₂)‖²          (연습문제는 κ = 2)
```

스프링 상수 `κ`, 자연 길이 0인 스프링이 두 접점을 당길 때의 **스프링 에너지**로 읽을 수 있습니다. `d = p(t₁) − p(t₂)`(현 벡터)라 하면 기울기는

```
∂E/∂t₁ =  κ · d · p′(t₁)
∂E/∂t₂ = −κ · d · p′(t₂)
```

기울기가 0이라는 것은 **현 벡터 `d`가 두 접점의 접선 `p′`와 모두 수직**이라는 뜻입니다. 즉 `d`가 두 접점의 **법선 방향**과 나란합니다. 교재가 말하는 대척(antipodal) 조건("접촉 법선이 서로 반대 방향이고 두 접점을 잇는 직선 위에 있음")과 같은 모양입니다. 그래서 대척점은 `E`의 **임계점**입니다.

이 문서의 질문은 그 다음입니다. **임계점이라고 다 같은 임계점이 아니고, 어떤 종류인가?** 그것을 가려내는 도구가 Hessian입니다.

## 2. Hessian이란

### 1변수에서: 2차 미분 = 휘어짐
`f(x)`에서 `f′(x*) = 0`인 점은 평평한 지점입니다. 그 점이 골짜기인지 봉우리인지는 `f″`가 정합니다.

- `f″ > 0`: 위로 오목한 그릇 모양 → **극소**
- `f″ < 0`: 아래로 볼록한 언덕 모양 → **극대**

### 2변수에서: 2×2 행렬
`E(t₁, t₂)`는 변수가 둘이라 2차 미분이 4개 나옵니다. 이를 모은 것이 **Hessian**입니다.

```
H = [ ∂²E/∂t₁²     ∂²E/∂t₁∂t₂ ]
    [ ∂²E/∂t₂∂t₁   ∂²E/∂t₂²   ]
```

- `H`는 대칭 행렬이라 **고유값이 실수**이고 서로 수직인 **고유벡터**가 있습니다.
- **고유벡터 `v`** 는 "에너지가 가장 곧게 휘는 방향", **고유값 `λ`** 는 그 방향으로의 휘어짐(2차 미분)입니다.
- `λ > 0`: 그 방향으로 가면 `E`가 **올라감**(그릇). `λ < 0`: 그 방향으로 가면 `E`가 **내려감**(언덕).

> **고유값 크기에 의미를 두지 않는 이유**: `t`의 속도가 빠른 매개변수화(예: 톱니바퀴 식의 `10t`)는 같은 모양이라도 Hessian 숫자가 수천~수만으로 부풀려집니다. 부호는 매개변수를 (방향을 유지하며) 바꿔도 변하지 않지만 크기는 변합니다.

## 3. 접점 쌍의 Hessian: 식과 기하학적 의미

임계점에서 `E`의 Hessian을 직접 전개하면 다음과 같습니다(`κ`는 스프링 상수).

```
∂²E/∂t₁² = κ ( ‖p′(t₁)‖² + d · p″(t₁) )
∂²E/∂t₂² = κ ( ‖p′(t₂)‖² − d · p″(t₂) )
∂²E/∂t₁∂t₂ = −κ · p′(t₁) · p′(t₂)
```

여기서 `p″`(경계의 2차 미분)가 **곡률**을 담고 있습니다. 2D 곡선에서 임계점 조건(`d`가 법선과 나란함)을 쓰면 아래처럼 단순해집니다. `d`는 현의 길이, `κᵢ`는 접점 `i`에서의 **볼록 곡률**(물체 바깥에서 볼 때 볼록하면 `+`, 오목하면 `−`)입니다.

```
H  ∼  [ 1 − d·κ₁     ±1      ]        (양의 대각행렬 스케일을 곱한 형태)
      [   ±1       1 − d·κ₂   ]

det(H) ∼ (1 − d·κ₁)(1 − d·κ₂) − 1
tr(H)  ∼ 2 − d·(κ₁ + κ₂)
```

> 양의 대각 스케일(`‖p′‖²` 등)을 곱해도 **고유값의 부호 패턴은 바뀌지 않습니다**(Sylvester 관성 법칙). 비대각 항의 부호 ±는 매개변수 방향에 따라 달라지지만 부호 패턴에는 영향이 없습니다(`det`와 `tr`에 안 나타남). 이 단순화는 직접 유도한 것이며, 톱니바퀴·타원 사례로 수치 확인했습니다.

`1 − d·κᵢ`는 **"현 길이 `d`와 접점의 곡률 반경 `1/κᵢ`의 비교"** 입니다. 곡률 반경이 현보다 크면(`d·κᵢ < 1`) 양수입니다. 이를 부호 판정에 넣으면 다음과 같습니다.

| 종류 | 조건 | 접점 모양으로 말하면 |
|---|---|---|
| **극소** | `1−dκ₁ > 0`, `1−dκ₂ > 0`, 곱 `> 1` | 두 접점이 모두 **오목**(`κ ≤ 0`)이면 항상 극소. 한쪽이 약간 볼록이어도 다른 쪽이 충분히 오목하면 가능. 예: 땅콩의 **잘록한 허리**, 톱니 사이 **홈** |
| **극대** | `1−dκ₁ < 0`, `1−dκ₂ < 0`, 곱 `> 1` | 두 접점이 모두 **볼록**하고 현이 두 곡률 반경보다 **긴** 경우. 예: 타원의 **장축 양 끝** |
| **안장** | 위 둘이 아님 (`det < 0`) | **오목·볼록이 섞였거나**, 볼록이어도 곡률 반경이 현보다 큰 쪽이 있는 경우. 예: 타원의 **단축 양 끝** |
| **퇴화** | `det = 0` | 예: **원**의 모든 지름(`d·κ = 2` → 고유값 `0`과 `−2κR²`) |

연습문제의 "극소/극대/안장은 물체 기하에서 무엇에 해당하나"라는 질문의 답이 이 표입니다. 오목한 곳은 거리가 **극소**, 볼록한 곳은 **극대**, 섞이면 **안장**입니다.

**장축 쌍(극대)**: 현을 돌려도, 접점을 함께 옆으로 밀어도 현이 **짧아집니다**. 어느 쪽으로 교란해도 에너지가 내려가므로 계속 어긋납니다.

**단축 쌍(안장)**: 현을 **회전**시키면 길어집니다(`+12`, 복귀). 그런데 두 접점을 **함께 옆으로 밀면** 짧아집니다(`−4`, 이탈). 한 방향은 안정이고 한 방향은 불안정이라 안장입니다.

이 숫자는 직접 확인할 수 있습니다. 구현 검증용으로 쓸 수 있도록 `t = [0, π]`(장축 쌍)에서 `[−16, −12]`, `t = [π/2, 3π/2]`(단축 쌍)에서 `[−4, 12]`가 나와야 합니다(`κ = 2`, 위 매개변수화 기준).

## 6. 미끄러짐·안정성과의 관계

### → 해석: 스프링으로 읽기
`E`를 "두 접점을 잇는 스프링의 에너지"로 보면, 접점이 표면 위에서 미끄러질 수 있을 때 접점은 에너지가 **낮아지는 쪽으로** 움직입니다. 그래서 Hessian의 종류가 다음 의미를 갖습니다.

| 종류 | 접점이 살짝 어긋나면 | 파지 관점에서 |
|---|---|---|
| **극소** | 스프링이 접점을 **제자리로 되돌림** | 교란에 강한 **기하학적으로 안정한** 파지. 오목한 부분이 손가락을 "붙잡아" 주는 효과 |
| **극대** | 어긋남이 **점점 커짐** | 가장 불리. 이 자세는 이론상 대척점이지만 **불안정한 균형점**이라 쉽게 이탈 |
| **안장** | 어떤 방향은 복귀, 어떤 방향은 이탈 | 중간. 한 방향의 교란에만 취약 |

### 마찰과는 어떻게 연결되나
접점 `i`에서 현이 법선과 이루는 각을 `φᵢ`라 하면 기울기 성분은 `d · ‖p′(tᵢ)‖ · sin φᵢ`에 비례합니다. 접점을 `δ`만큼 미끄러뜨린 뒤 기울기는 대략 `H δ`입니다. 즉 **Hessian은 "접점이 조금 미끄러졌을 때 현이 법선에서 얼마나 빨리 벗어나는가"** 를 알려줍니다.

- 현이 법선과 정확히 일치하면(`φ = 0`) 법선력만으로 균형이 잡히고 마찰은 필요 없습니다.
- 접점이 미끄러져 `φ`가 생기면 **마찰원뿔** 안에 들어야 합니다(`tan φ ≤ μ`).
- **`|λ|`가 크면** 작은 미끄러짐에도 `φ`가 빠르게 커져 마찰 한계를 넘기기 쉽습니다. **`λ`의 부호**는 그 어긋남이 되돌려지는지(`+`) 더 커지는지(`−`)를 정합니다. (`|λ|` 크기는 매개변수화 의존이므로 `‖p′‖`, `d`로 정규화해서 비교해야 의미가 있습니다.)

### Hessian이 알려주지 않는 것
| 알려주는 것 | 알려주지 않는 것 |
|---|---|
| 접점이 표면을 따라 **미끄러질 때** 대척 배치가 유지되는 경향(안정/불안정) | 마찰계수가 충분한지, 힘의 크기 |
| 불안정 방향이 있는지 | **force closure**(접촉 렌치 원뿔이 전체 공간을 덮는지). 두 점 접촉은 비틀림 마찰 없이는 현 축 둘레 토크를 못 견딤(교재도 언급) |
| 곡률 때문에 생기는 국소적 성질 | 물체 전체의 회전·중력·관성, 손가락 컴플라이언스 |

따라서 **"극소면 반드시 안전, 극대면 반드시 실패"가 아니라, 후보를 정렬하는 기하학적 단서**입니다. 마찰이 충분히 크면 극대 쌍도 정적으로는 쥘 수 있지만 교란에 취약합니다.

## 7. 구현할 때 확인할 점 (Exercise 3·4단계)

- **Hessian은 대칭**이라 `np.linalg.eigvalsh`가 실수 고유값을 안정적으로 줍니다(노트북은 `eigvals`를 안내하며, 대칭 행렬이면 결과는 같습니다).
- 임계점 찾기는 비볼록 방정식이므로 **무작위 초기값 반복**이 필요합니다. `p(t₁) = p(t₂)`인 자명한 해는 `ε` 제약으로 제외됩니다.
- 부호 분류 때 **`0`에 가까운 값**은 퇴화(원 같은 연속 대칭)일 수 있으니 허용 오차를 둡니다.

```python
def classify(eig, tol=1e-6):
    if (eig >  tol).all(): return "min"       # 모두 양수
    if (eig < -tol).all(): return "max"       # 모두 음수
    if (eig >  tol).any() and (eig < -tol).any(): return "saddle"
    return "degenerate"
```

- 구현이 맞는지는 **타원 닫힌 해**(4절)와 비교하면 가장 빨리 확인됩니다.

- **LEAP Hand·일반 물체로 확장할 때**: 후보 파지를 **샘플링으로 만들고**, 각 후보의 곡률로 위 분류를 매겨 **극소 > 안장 > 극대** 순으로 정렬하는 필터를 생각할 수 있습니다. 해석적 방법은 형상이 식으로 주어져야 하므로, 실물에서는 [점군](../point-cloud/)에서 메시/SDF를 만든 뒤 곡률을 추정해야 합니다. 교재가 모델 기반 최적화를 일부러 피한다고 말하는 이유와도 맞닿는 지점입니다.
- 우리 과제의 핵심인 "무교란 파지"와의 연결: **극대 쌍은 접촉 순간의 작은 밀림이 증폭될 수 있다**는 뜻이라, 접촉이 비동기일 때 특히 위험한 자세 후보를 미리 걸러내는 기준이 될 수 있습니다. 아직 검증한 적 없는 가설입니다.
