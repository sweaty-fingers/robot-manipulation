## 한 줄 요약

시뮬레이션에서 RL로 학습한 하나의 컨트롤러가, 깊이 카메라 1대와 관절 위치만으로 새로운 형상 물체를 임의 회전으로 손 안에서 재배치한다(중앙값 약 7초, 제로샷 실기 전이).

## 풀려는 문제

기존 재배치 연구는 특정 단순 물체, 제한된 회전, 느린(quasi-static) 조작, 시뮬레이션 한정, 고가 센서 구성 중 하나 이상을 전제했다(초록). 이 논문은 이 가정들 없이 새로운 형상 물체에 일반적으로 동작하는 컨트롤러를 목표로 한다.

## 핵심 아이디어

1. **교사-학생 학습.** 교사 정책은 시뮬레이션의 **특권 정보**(손끝 속도, 물체 자세·속도 등 실세계에서 재기 어려운 값, Methods)로 PPO 학습. 학생 정책은 교사를 DAgger로 모방하며 실제로 얻을 수 있는 관측만 쓴다.
2. **2단계 학생 학습(Teacher-student²).** 1단계는 렌더링 없이 메시에서 샘플한 완전한(가림 없는) 합성 포인트클라우드로 학습(약 7배 빠름), 2단계는 렌더링된 깊이 포인트클라우드로 미세조정. 시뮬레이션 렌더링 비용 때문에 학생 학습이 20일 이상 걸리던 문제를 줄임(Methods, Fig. 7C).
3. **로봇 자신의 몸을 포인트클라우드로.** 관절 각도 → 순기구학 → 손가락 표면 포인트클라우드("proprioceptive point cloud")를 카메라 포인트클라우드에 합쳐, 손가락과 물체의 공간 관계를 네트워크가 보게 한다(Methods).
4. **목표를 자세가 아닌 포인트클라우드로.** 목표 자세의 물체 포인트클라우드를 입력(물체마다 기준 좌표계를 정할 수 없어 포즈 추정기가 일반화되지 않기 때문, Methods).
5. **순응성 하드웨어.** 부드러운 엘라스토머 손끝으로 마찰·접촉 면적을 늘림. 손끝이 "덜 공격적이고 오버슈트가 줄었다"고 보고(Results).

### 입력(관측)과 출력(행동)

| | 내용 |
|---|---|
| 관측 | 깊이 이미지(RealSense 1대)→포인트클라우드 + 관절 위치(엔코더). 목표 포인트클라우드. **읽은 범위에서 촉각 센서는 쓰지 않음** |
| 행동 | 관절 상대 위치 변화, 위치 컨트롤러, **12Hz**. 행동의 지수이동평균(α=0.8)으로 평활화 |
| 학습 | 시뮬레이션(Isaac Gym) RL(PPO) → DAgger 증류. 물체 150개(학습), 12개(ContactDB, 테스트) |

보상 항(Methods, Eq. 1–5): 성공 희소 보상, 목표 자세 오차 밀집 보상, **손끝-물체 거리 패널티**(없으면 학습 중 손가락이 거의 접촉하지 않음), 에너지 패널티, **물체를 손에서 너무 멀리 밀면 패널티+에피소드 종료**.
일반화를 위해 학습 중 물체에 **무작위 외력**을 가하고, 로봇 동역학은 CMA-ES로 시스템 식별(Methods).

## 결과

- 테이블 위, 3지 D'Claw 손(9 DoF), 목표 0.4rad(22.9°) 이내 성공률(Table 1): 학습 물체 실기 **81%**(딱딱한 손끝)/79%(부드러운 손끝), 미학습 물체 **45% → 55%**(딱딱 → 부드러운). 시뮬레이션은 96%/85%.
- 공중 재배치는 **4지(12 DoF)** 손만 가능(3지는 떨어뜨림). 시간 중앙값 **7초 미만**(Fig. 4D). 오리 모양 미학습 물체는 실기에서 **56%를 떨어뜨림**(학습 물체 트럭 23%, 시뮬레이션 오리 약 20%).
- 오차의 큰 원인 중 하나는 **멈춤 판단 실패**. 저자는 이쪽이 행동 예측 오차보다 더 기여한다고 가설(Results).

## 한계

- **저자가 말한 한계**: 절대 성능 개선 여지가 큼. 시뮬레이션과 실기 사이 간극(재배치 시간이 실기에서 더 김). 오리의 높은 낙하율이 시뮬레이터 근사 때문인지 물체가 실제로 더 어려워서인지 구분 불가.
- → 해석: 제어가 12Hz라 접촉 순간의 빠른 반응은 설계 대상이 아님. 평가가 재배치 정확도라서 **접촉하는 순간 물체가 얼마나 밀렸는지는 보고되지 않음**(읽은 범위 기준).

## 우리 과제와의 관련

| 관점 | 내용 |
|---|---|
| 접촉 처리 | 접촉을 명시적으로 모델링하지 않고 RL이 암묵적으로 학습. 거친 수준의 "너무 멀리 밀기" 패널티만 있음 |
| 센서 가정 | **촉각 없이** 비전(깊이)+proprioception으로 접촉 리치 과제가 된다는 증거 |
| 가져다 쓸 것 | ① 교사(특권 정보) → 학생(비전+proprio) 구조. → 해석: 시뮬레이터의 접촉력을 교사에게 주고 학생은 안 쓰면, 촉각 없이 접촉 정보를 간접 학습시킬 수 있음. 이후 촉각을 학생에 추가하는 확장과도 자연스럽게 이어짐 ② 손가락 포인트클라우드를 proprioception으로 만드는 표현 ③ 순응성 손끝(하드웨어로 접촉 충격을 줄이기) ④ 학습 중 무작위 외력 |
| 다른 점 | 과제가 파지 *획득*이 아니라 쥔 뒤의 재배치. 손가락 3–4개, 위치 제어 12Hz. 접촉 시퀀스 교란 지표 없음 |

## 검증 로그

- 읽은 부분: Results 전체, Materials and Method 전체(arXiv v3 LaTeX).
- 읽지 않은 부분: Summary, Introduction, Discussion, Supplementary Methods/Discussion(관측 세부, 성공 기준 세부, 멈춤 예측기 등).
- 확인 못 한 주장: "촉각을 쓰지 않는다"는 읽은 섹션에서 관측이 깊이+관절 위치로만 기술돼 있다는 의미. 전체 문서에서 촉각 언급이 없다는 확인은 안 함.
