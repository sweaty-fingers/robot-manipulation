개념 문서를 쓸 때 여기 항목으로 링크를 걸어 쓰는 것을 전제로 정리했습니다.

## 개념 문서에서 연결하는 법

논문 목록의 각 항목은 영문 이름 제목이라 앵커가 예측 가능합니다. 상대경로로 연결하세요.

```md
[Visual Dexterity](../references/papers/#visual-dexterity)
```

(`references/` 안의 다른 페이지에서는 `../papers/#visual-dexterity`.)
새 자료를 추가할 때는 `papers.md`의 해당 분류 아래에 같은 형식의 섹션을 하나 더 만들면 됩니다.

## 검증 상태 표기

이 섹션의 모든 항목에는 얼마나 확인했는지가 붙어 있습니다. 빠르게 바뀌는 분야라 구분이 중요합니다.

- **초록 확인**: 2026-11-14 세션에서 arXiv 초록을 직접 읽고 쓴 내용. 본문·실험 세부는 읽지 않았습니다.
- **원문 미확인**: 이전 리서치 브리프나 검색 스니펫에서 가져온 내용으로, 이번에 원문을 열어보지 못했습니다. 인용 전에 확인이 필요합니다.
- **벤더 표기**: 가격·스펙이 판매처/블로그 표기라 변동·불일치 가능.

본문 전체를 읽은 논문은 아직 없습니다. 개념 문서에서 수치를 인용할 때는 원문을 열어 확인한 뒤 이 표기를 갱신하세요.

## 목록과 상세를 나누는 이유

- **목록**(`papers/index`)은 훑어보고 비교하는 용도라 한 줄 요약만 둡니다. 새 자료는 표에 한 줄 추가하면 끝.
- **상세**(`papers/<slug>`)는 읽을 가치가 있다고 판단한 자료만 만듭니다. 미리 전부 만들지 않고, 읽다가 정리를 요청하면 그때 작성합니다.
- 상세 페이지를 만들면 목록 항목의 요약 끝에 `**[상세 →](slug/)**`를 붙입니다. 링크가 없는 항목은 상세가 아직 없는 것.
- 링크는 두 수준을 모두 지원합니다: 목록 항목 `../references/papers/#visual-dexterity`, 상세 `../references/papers/visual-dexterity/`.

## 상세 페이지 템플릿

템플릿: [`references/papers/_template.md`](https://github.com/sweaty-fingers/robot-manipulation/blob/main/src/content/docs/references/papers/_template.md)
(`_`로 시작해 사이트에는 렌더링되지 않음). 예시: [Visual Dexterity](papers/visual-dexterity/).

고정 구조(v0.1): 정보 표 → 한 줄 요약 → 풀려는 문제 → 핵심 아이디어(관측·행동·학습 표 포함) → 결과 → 한계 → **우리 과제와의 관련** → 검증 로그 → 열린 질문 → 관련 항목.

규칙:
- 논문에 있는 **사실**에는 위치(섹션·표·그림)를 달고, 내 **해석**은 `→ 해석:`으로 구분.
- 읽은 범위와 못 읽은 부분을 검증 로그에 반드시 적는다.
- **템플릿을 바꿀 때**: `_template.md`의 `template:` 값을 올리고(v0.1 → v0.2), 이 아래 변경 기록에 한 줄 적는다. 구버전 페이지는 frontmatter의 `template` 값으로 찾을 수 있어 일괄이 아니라 필요할 때 옮긴다.
