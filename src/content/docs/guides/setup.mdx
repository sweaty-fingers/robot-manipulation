import { Tabs, TabItem } from '@astrojs/starlight/components';

이 레포는 두 개의 독립된 툴체인을 같은 git 레포에서 관리합니다 — 문서 사이트(Node/Astro)와
`robot_manipulation` 패키지(Python)는 서로 영향을 주지 않습니다.

<Tabs>
	<TabItem label="문서 사이트 (Node)">
		```bash
		npm install
		npm run dev
		```

		`http://localhost:4321`에서 확인. `src/content/docs/` 아래 `.md`/`.mdx` 파일을
		수정하면 즉시 반영됩니다.
	</TabItem>
	<TabItem label="Python 프레임워크 (uv)">
		```bash
		uv venv .venv
		uv pip install --python .venv/bin/python -e ".[dev]"
		pytest tests/
		```

		GPU/시뮬레이터 환경이 로컬에 없다면 [Colab 실습 가이드](../colab-quickstart/)를 사용하세요.
	</TabItem>
</Tabs>

## 새 문서 페이지 추가

1. `src/content/docs/<섹션>/<파일명>.md`(또는 Tabs/Steps 같은 컴포넌트가 필요하면 `.mdx`) 생성, 상단에 frontmatter(`title`, `description`) 작성
2. `astro.config.mjs`의 `sidebar`에 새 항목 추가 — 등록 안 하면 내비게이션에 안 뜸
3. 내부 링크는 항상 상대경로로 작성 (`../section/page/`) — GitHub Pages가 `/robot-manipulation/` 서브패스에서 서빙되기 때문에 절대경로는 404가 남
4. `npm run build`로 빌드 오류/깨진 링크 확인
